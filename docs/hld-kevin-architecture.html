DECISION FUSION & INFERENCE

Decision Weight Fusion & Service

  • Decision Weight Fusion: Fuses calibrated heuristic baselines with optional model weights (text-classification, zero-shot, generation, feature-extraction embeddings).
  • Daemon Inference Sessions: WebSocket daemon on 127.0.0.1:9222 hosts lazy pipeline sessions via wire protocol INFER endpoint with InferenceTransport.
  • Verify-and-Retry Loop: AgentRuntime.runTask with requireVerify & maxAttempts verifies assertions via verifyCondition, feeding failure notes back into replanning (exhaustion returns verified:false).

HIGH-THROUGHPUT PERCEPTION

Onyx Candidate Ranker & Cache

  • Microsecond Gating: Parallel dot-product candidate ranking prunes 500+ raw DOM nodes to Top-15.
  • Self-Healing Cache: SHA-256 DOM fingerprint lookup delivers <1ms instant replay execution.
  • DOM Mutation Stability: waitForDomSettle ensures zero race conditions on dynamic routes.

SURFACES & SAFETY

Universal Runtime & Risk Gate

  • Multi-Surface Architecture: Native Playwright agent, JSON-RPC MCP server (with kevin_infer), WebSocket daemon (127.0.0.1:9222), MV3 HUD.
  • Pure Security Risk Gate: Deterministic Low/Medium/High classification intercepting sensitive actions.
  • 100% Data Privacy: Zero DOM HTML, credentials, or cookies ever exfiltrate the local machine.
