PURE FUNCTIONAL CONTRACTS

Zero Hidden State Rule

  • Deterministic Output: Boxes 1–6 and Box 8 (browserDecision) act as pure functions: identical inputs guarantee identical outputs without side effects.
  • Explicit Arguments: No hidden global state, environment variables, or module closures affect logic.
  • Isolated Side Effects: All physical CDP mutations are strictly cordoned off inside Box 7 (BrowserEngine).

DECISION FUSION & VERIFY LOOP

Box 8: Decision Fusion & Verify Loop

  • Decision Weight Fusion: Box 8 (browserDecision) fuses heuristic baselines with optional modelOutput (text-classification labels, zero-shot, generated tokens, embeddings cosine similarity).
  • Verify-and-Retry Stage: AgentRuntime.runTask (with requireVerify: true, maxAttempts) and planActVerifyStep evaluate verifyCondition after action execution.
  • Feedback & Exhaustion: Verification failure notes feed back into goal & context replanning; attempt exhaustion returns verified: false.

STATEFUL STORES & SYSTEM ISOLATION

Stateful Stores: System Stateful, Boxes Pure

  • Inference Sessions: Daemon inferSessions Map (packages/daemon/infer.ts) and NanoClient cache lazy pipeline instances across calls.
  • Action Cache: ActionCache maintains SHA-256 DOM fingerprint lookup tables for <1ms instant replay.
  • Context Memory: ContextMemory.lastTarget & turns history preserve conversational state across turns.
  • System vs Pure: Core pipeline boxes remain 100% pure; system statefulness is quarantined strictly to these explicit stores.
